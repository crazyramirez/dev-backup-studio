Full server backups (settings, subscriptions, websites, databases and mail) made with Plesk's own
backup tool (`pleskbackup --server`) and kept on your own disk by the **DEV Backup Studio** desktop app
for Windows, macOS and Linux.

* Connect a computer with a one-time 6-digit code: no passwords, no SSH.
* Each backup is downloaded, checked with SHA-256 and stored in the `PLESK` folder of your backup drive.
* Restore the Plesk way: the whole server with `pleskrestore`, or upload the backup to the Backup
  Manager and choose there what to restore.
